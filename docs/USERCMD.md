# smac_usercmd — диагностика usercmd (без наказаний)

Модуль ничего не наказывает. Он пишет в `logs/smac_usercmd_diag.log`, чтобы подобрать пороги на живых игроках,
как `smac_ultra_diag_norecoil`. Идеи взяты из разбора читов CSS v34 (insomnia, pizzahook, sega).

## MoveGrid — движение не с клавиатуры

Клиент собирает движение только из клавиш:

```
forwardmove = a * cl_forwardspeed - b * cl_backspeed
sidemove    = (c - d) * cl_sidespeed          a..d = KeyState: 0, 0.25, 0.5, 0.75, 1
```

`+speed`, присед и `ScaleMovements` (ограничение до maxspeed оружия) умножают обе оси на одно число, поэтому
отношение `|sidemove / forwardmove|` всегда из маленького набора: при 400/400/400 это 11 значений
(1/4, 1/3, 1/2, 2/3, 3/4, 1, 4/3, 3/2, 2, 3, 4). Скорости модуль запрашивает у клиента.

Читы после изменения углов поворачивают вектор движения, чтобы игрок шёл куда смотрит (insomnia `FixMove`,
pizzahook автострейф `forwardmove = cos(yaw) * speed`, sega `Correct_Movement` с округлением до целого), и
отношение получается любым. Считаются команды, где обе оси ненулевые.

Модель: обычный ввод с шагом, присед и ограничением скорости — **0 из 128 350** команд вне сетки; повёрнутый вектор
— **98,8 %** вне сетки (допуск 0,3 %).

Обычные игроки тоже могут дать «чужие» отношения: джойстик (`joystick 1` — пропускается), `+strafe` мышью,
`cl_mouselook 0` (`m_forward`/`m_side`). Это и надо увидеть в логах.

## SnapBack — рывок на одну команду

Взгляд прыгает на ≥ 2° ровно на одну команду, а следующая возвращается в пределах 0,1° туда, где был.
Рука так не может за один тик; так выглядят silent aim (угол на цель только в команде выстрела) и jitter
анти-аима. Если в команде рывка был `+attack` — «silent shot», иначе — «jitter». После пропуска cmdnum
история сбрасывается, чтобы потерянные пакеты не выглядели рывком.

## Квары и команды

| | По умолчанию | |
|---|---|---|
| `smac_usercmd_diag` | 1 | 0 — выкл. |
| `smac_usercmd_diag_samples` | 20 | сколько сырых примеров на игрока за карту писать в лог |
| `sm_usercmd_diag` | | счётчики всех игроков в консоль (флаг generic) |

Сводка на игрока — раз в 5 минут и при выходе:
`summary: cmds N | MoveGrid off-grid X of Y (Z%) | SnapBack silent shots S, jitter J`.

## Что смотреть в логах

* MoveGrid off-grid у обычных игроков: должно быть около 0 %. Если у кого-то много — смотреть примеры (джойстик,
  `+strafe`, нестандартные `cl_*speed`).
* SnapBack у обычных игроков: должно быть 0 или единицы за карту.
* Когда станет понятен разброс у чистых игроков — можно ставить пороги и реакцию.
