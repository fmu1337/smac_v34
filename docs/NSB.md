# smac_nsb — no-steam баны

Многие наверное сталкивались с игроками, которых банишь и они опять лезут и лезут. Плагином прикроем им вход.

Требования: SMAC, CS:S v34.

Список банов: `addons/sourcemod/data/smac_nsblist.txt`. При старте подтягивает ещё не скопированные записи из `data/kac_nsblist.txt`.

## Квары

| Квар | По умолчанию | |
|---|---|---|
| `smac_nsb` | 1 | 0 — выкл. |
| `smac_nsb_banip` | 1 | 0 / 1 IP / 2 /24 / 3 /16 |
| `smac_nsb_banip_time` | 45 | минуты для `addip` |
| `smac_nsb_steamid` | 1 | 1 — ещё `sm_ban`, 0 — только кик |
| `smac_nsb_fail` | 1 | нет ответа на запрос: 0 лог, 1 кик |
| `smac_nsb_restore` | 200 | через сколько секунд проверка, выключенная из меню, включится сама. 0 — не включать |
| `smac_nsb_warn` | 25 | как часто напоминать админам, что проверка выключена. 0 — молчать |

Бан и разбан — в админ-меню (Управление игроками) и через `sm_nsb`.
