# Таблица кваров SMAC Ultr@ R52 в smac_cvars

Таблица восстановлена эмуляцией `OnPluginStart` плагина `001_SMAC_Cvars.smx` из SMAC Ultr@ R52 (`docs/R52_CVARS.md`
в ветке с декодом). Она лежит в `addons/sourcemod/scripting/include/smac_cvars_ultra.inc`. Этот файл сгенерирован из
декода; правки в нём нужно сверять с `R52_CVARS.md`.

## Что в таблице

| Группа R52 | Записей | Проверка |
|---|---|---|
| `Check_Hack` | 72 | квар или команда **не должны существовать**: Lua/скрипт-движки, «takeover»-плагины, консоли читов. Сюда же входят `*_version` известных серверных модов (кик) |
| `Check_Changer` | 84 | не должны существовать: смена SteamID и ника, меню читов (`*_show_steam`, `*_steam_set_id`, `esp`, `aimbot`, `wallhack`, …) |
| `Check_CheatsC` | 169 | клиентские настройки с фиксированным значением (`equal`), а также `mat_dxlevel` ≥ 80, `fps_max` 30…1000, `cl_interp_ratio` и `cl_pred_optimize` 1…2 |

Всего 325 кваров; 68 из них `smac_cvars` уже проверяет сам, и для них остаются его собственные настройки (R52 их
не перетирает). Добавляются 257 новых.

## Управление

`smac_cvars_ultra`:

| Значение | Поведение |
|---|---|
| 0 | таблица R52 не используется |
| **1** (по умолчанию) | только уведомление админам и запись в лог; по каждому квару — один раз за заход игрока |
| 2 | кик или бан, как в R52 |

Квар можно менять на лету: записи таблицы снимаются и добавляются заново.

Для записей R52 ответ клиента «квар не найден» или «защищён» **не считается нарушением** для проверок значения (`equal`,
`greater`, `between`). В `smac_cvars` любой ответ, кроме «ok», ведёт к действию; для таблицы R52 это опасно, потому
что часть кваров может отсутствовать в конкретной сборке клиента v34. Для проверок «не должен существовать»
поведение прежнее: нарушение — любой ответ, кроме «не найден».

Заодно действие `Warn` в `smac_cvars` теперь действительно уведомляет админов и пишет в лог; раньше оно ничего не делало,
кроме вызова форварда. Это касается и кваров, добавленных через `smac_addcvar ... warn`.

## Риски для режима 2

* **Общие имена в «не должно существовать»**: `run`, `go`, `file`, `lua`, `id`, `steam`, `hack`, `esp`, `dk`, `by_`,
  `open`. Если в клиенте есть команда с таким именем, это нарушение (так же, как в R52).
* **`fps_max` вне 30…1000**: `fps_max 0` (без ограничения) — нарушение.
* **`developer`, `cl_drawhud`, `r_drawviewmodel`, `default_fov`, `viewmodel_fov`, `cl_bob*`**: игроки иногда меняют их
  сами; в R52 за это кик.
* `net_fakelag`, `net_fakeloss`, `voice_inputfromfile`, `voice_loopback`, `cl_predict`, `cl_lagcompensation` в R52 —
  **кик**, не бан.
* `cl_interpolate` в таблице R52 **нет**.

Перед включением режима 2 стоит несколько дней посмотреть лог на режиме 1.
