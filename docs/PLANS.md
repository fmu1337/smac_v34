## Игнор игроков в anti-WH

В старой сборке v34.R1f у `smac_wallhack` были natives `SMAC_WH_SetClientIgnore` / `SMAC_WH_GetClientIgnore`
(`include/smac_wallhack.inc`), а `smac_wallhack_ucp_legit` / `smac_wallhack_ucpd` через них снимали проверки видимости
с игроков с клиентским античитом UCP. UCP мёртв, поэтому эти модули не возвращаем.

Сам механизм остался: в `smac_wallhack.sp` есть массив `g_bIgnore`, сейчас он ставится только ботам. Если вернуть
natives, другие плагины смогут исключать игроков из проверок, например:

* игроков с другим клиентским античитом или доверенных (по SteamID, флагу админки);
* спектаторов и HLTV-подобные слоты, чтобы снизить нагрузку;
* временно — игроков, которых админ смотрит вручную.

Стоит решить: нужен ли такой «белый список» вообще (это дыра, если флаг выдаётся небрежно), и не проще ли сделать
квар с флагом админки внутри `smac_wallhack` без внешних natives.
