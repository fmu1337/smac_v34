# smac_cvar_trap — ловушка на кваре `xbox_throttlebias`

## Зачем

На no-steam серверах CSS v34 в архивных кварах `xbox_*` хранят метки:

* **NoSteamBans** (KAC/kigen NSB) пишет игроку `xbox_throttlespoof` ≠ 200 и банит по нему, потому что SteamID на
  no-steam меняется, а `config.cfg` остаётся.
* **SteamID Protect** хранит пароль игрока в `xbox_autothrottle`.

Чит **Insomnia** (CSS v34) и сборки на его основе каждый кадр (`Hooked_PaintTraverse`, панель `MatSystemTopPanel`)
возвращают все три квара к значениям по умолчанию — `xbox_autothrottle 1`, `xbox_throttlebias 100`,
`xbox_throttlespoof 200` (в исходнике это подписано `// leet ruski antiban`). Обычный клиент эти квары сам не трогает:
на ПК `xbox_*` ни на что не влияют. Значит, если записать туда своё значение и через пару секунд снова увидеть 100,
значение сбросил чит.

## Как работает

1. `OnClientConnected` — игрок «взводится». На `OnClientPutInServer` запрашивается `xbox_throttlebias`.
   Если там не 100, проверка пропускается: сейчас его никто не сбрасывает.
2. MOTD, который игра шлёт при входе (`VGUIMenu "info"`), перехватывается и придерживается до ответа на запрос
   (не дольше 5 с; без ответа MOTD уходит как был). Если ответ 100, в ключ `cmd` (команда при закрытии MOTD)
   дописывается
   ```
   xbox_throttlebias <случайное 101..9999>;smac_cvar_trap_ack <токен>;<исходный cmd, обычно joingame>
   ```
   Клиент v34 выполняет `cmd` через `engine->ClientCmd`, когда игрок жмёт OK.
3. `smac_cvar_trap_ack` клиенту неизвестна и уходит на сервер. Раз она пришла, строка выполнилась, и квар был выставлен
   до неё. Через `smac_cvar_trap_delay` с (2 с) квар запрашивается снова:
   * наше значение — чисто;
   * 100 — сброшен на значение по умолчанию → детект `Cvar Trap (xbox_* reset)` (`Detection_CvarTrap`, 7800);
   * что-то третье — только запись в лог (его поменял кто-то другой).

Наше значение остаётся у игрока (на ПК `xbox_throttlebias` ни на что не влияет). На следующей карте первый запрос
увидит его и проверку пропустит — пока чит снова не вернёт 100. `xbox_throttlespoof` (NSB) и `xbox_autothrottle`
(SteamID Protect) модуль не трогает.

## Квары

| Квар | По умолчанию | |
|---|---|---|
| `smac_cvar_trap` | 1 | 0 — выкл. |
| `smac_cvar_trap_action` | 0 | 0 — уведомление админам и лог, 1 — кик, 2 — бан |
| `smac_cvar_trap_delay` | 2.0 | секунд между ack и проверочным запросом |

## Ограничения

* Только движок 2006 (CSS v34). На Orange Box `cmd` у MOTD — число, а `engine->ClientCmd` выполняет только команды
  с `FCVAR_CLIENTCMD_CAN_EXECUTE`; там модуль пишет в лог и ничего не делает. Если `cmd` в MOTD числовой или
  длиннее 126 символов, проверка тоже пропускается.
* Срабатывает только когда игрок закрывает MOTD кнопкой OK. Кто сидит в MOTD, того не проверяют.
* Плагины, которые сами подменяют MOTD через тот же `VGUIMenu`, могут перехватить его раньше или позже — тогда
  ловушка просто не добавится.
* **Не проверено в игре.** Перед `smac_cvar_trap_action 1/2` нужно убедиться на живом сервере, что у чистых игроков
  после OK приходит `smac_cvar_trap_ack` и квар читается обратно, а у игрока с Insomnia — 100.
