# smac_ultra_diag_norecoil — диагностика No Recoil A/B из SMAC Ultr@ R52

Этот плагин **никого не наказывает**. Он отвечает на один вопрос: срабатывал бы No Recoil из R52 на обычных игроках?

## Зачем

No Recoil A/B в R52 сравнивает углы usercmd с `m_angEyeAngles`, прочитанным в pre-hook `OnPlayerRunCmd`. Если там
`m_angEyeAngles` всегда равен углам **прошлого** cmd (так выходит по коду движка), то условие A выполняется при любом
спрее с движением мыши, и R52 банил бы обычных игроков. Раз R52 этого, судя по всему, не делал, где-то есть эффект,
который по декомпиляции не виден. Плагин меряет это на живом сервере и прогоняет логику R52 один в один
(разбор — `docs/R52_SPEC.md` §6a в ветке декода).

## Что пишет

Лог: `addons/sourcemod/logs/smac_norecoil_diag.log`.

* **sample** — первые N случаев за карту на игрока, когда `m_angEyeAngles` ≠ углам прошлого cmd: номер cmd, tickcount,
  углы прошлого и текущего cmd, `m_angEyeAngles`, кнопки.
* **R52 would arm 1101 / 1102** — момент, когда R52 поставил бы проверку A / B, с причиной и оружием.
* **R52 WOULD PUNISH** — счётчик `cnt[42]` превысил `|smac_NoR_Ban|`: здесь R52 кикнул или забанил бы игрока.
* **summary** — раз в 5 минут и при выходе игрока:
  * `cmds` — сколько cmd учтено (живой игрок);
  * `eye!=prev` — сколько раз `m_angEyeAngles` не совпал с углами прошлого cmd (и процент) — **главная цифра**;
  * `eye==this` — сколько раз `m_angEyeAngles` уже равнялся углам текущего cmd при движении прицела;
  * `held+moving` — cmd с зажатой атакой и движущимся прицелом;
  * `shots`, `would arm 1101`, `1102`, `would punish`.

`sm_norecoil_diag` (флаг generic) печатает те же цифры по всем игрокам в консоль.

## Квары

| Квар | По умолчанию | |
|---|---|---|
| `smac_norecoil_diag` | 1 | 0 — выключить |
| `smac_norecoil_diag_samples` | 20 | сколько сырых примеров писать на игрока за карту |
| `smac_norecoil_diag_ban` | 5 | `|smac_NoR_Ban|` для прогона (в R52 по умолчанию 5) |

## Как читать результат

1. Положить `smac_ultra_diag_norecoil.smx` в `plugins/`, поиграть обычными игроками с автоматами минут 20–30.
2. Посмотреть `summary` и `sm_norecoil_diag`:
   * **`eye!=prev` около 0%, а `would arm 1101` и `WOULD PUNISH` есть у обычных игроков** — гипотеза верна: No Recoil A
     из R52 в таком виде ловит обычный спрей, переносить его как детект нельзя.
   * **`eye!=prev` заметно больше 0%** — движок v34 обновляет `m_angEyeAngles` не так, как в SDK. Тогда по `sample`
     видно, на что он похож (на углы этого cmd, на старые, с отдачей), и по этому можно понять, что на самом деле
     ловит R52.
   * **`would punish` нет вообще, хотя игроки стреляли с движением мыши** — значит, условие R52 не выполняется у обычных
     игроков, и детект можно переносить.
3. Прислать кусок лога — по нему решим, переносить ли No Recoil и в каком виде.

Плагин не трогает cmd и не меняет игру; нагрузка — два чтения пропов на cmd.
