# Changelog

История версий SMAC v34, собранная по теме на hlmod: https://hlmod.net/threads/smac-v34.28266/
(20 страниц, апрель 2015 — июнь 2021) и по истории этого репозитория.
Номер поста указан там, где пункт взят из конкретного сообщения (`#post-NNNNNN`).

Основа — SMAC 0.8.5.1 / 0.8.6.0 (smac.sx), портированный Danyas под CS:S v34.
Помощь в разработке: Александр <Ultr@> Смирнов, WINS, SkorP1onS, Reg1oxeN.

## Известные проблемы и советы из темы
- **KAC выгружает SMAC.** KAC при старте переносит `smac.smx` в `plugins/disabled`. Не ставьте оба античита; если очень нужно, переименуйте `smac.smx` (#post-470461, #post-470975).
- **Краш клиентов при взрыве бомбы.** Связан с `smac_wallhack` и конфликтом с Round End Sound от FrozDark. Частично исправлено в b3/R1f, у части серверов осталось (#post-254874, #post-254925).
- **Ложные баны eyetest.** Проверка `buttons` («tampering with an old movement command») отключается через `smac_eyetest_compat 1`, в R1f удалена. `UserCmdReuse` («reusing old movement commands»), по мнению тестеров, ловит NoShake/NoSpread (NeonHack).
- **Autotrigger.** Возможны баны за bhop/autofire без читов (прыжок на колесе, частые клики). Используйте `smac_autotrigger_action 1` (кик). В мае 2016 автор советовал брать autotrigger из b3 (#post-250020).
- **Aimbot.** Детект по углу ≥ 45° на дистанции ≥ 200, бан с 4-го детекта. Слабый аим не ловится; если уменьшить угол, будут ложные баны (#post-266211).
- **`smac_status_show` работает наоборот**: `1` скрывает status, `0` показывает (#post-273660).
- **`smac_cvars` требует `basecomm`**, поэтому не грузится с MaterialAdmin, который его выгружает. Есть патч под нативы MA (#post-288427).
- **Баны идут через `sm_ban`** для совместимости с SourceBans и basebans. Если игрока не кикает, проблема в плагине банов (#post-253916, #post-262148).
- **`smrcon` не существует под v34.** Ошибки `smac_rcon_ext` в b1 можно игнорировать (#post-226976).
- **Нагрузка.** `smac_wallhack` заметно грузит CPU, особенно на Linux и при большом онлайне.
